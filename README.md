# 🍱 Site de Venda de Comidas Orientais

Bem-vindo ao **Site SENAI - Comidas Orientais**, um projeto desenvolvido para apresentar e vender pratos típicos da culinária oriental de forma simples, moderna e responsiva.  
O objetivo do site é proporcionar uma experiência agradável ao usuário, destacando sabores, tradições e a praticidade dos pedidos online.

---

## 🧾 Sobre o Projeto

O site foi criado como parte de um projeto educacional no **SENAI**, com foco em **desenvolvimento web**.  
Ele simula uma plataforma de **restaurante virtual** onde o usuário pode visualizar o cardápio, conhecer a história do restaurante e realizar pedidos.

---

## 🥢 Funcionalidades

- Página inicial com destaque dos principais pratos  
- Seção “Sobre” apresentando a história e valores da marca  
- Cardápio completo com imagens e descrições  
- Página de contato com formulário funcional  
- Layout responsivo para computadores, tablets e celulares  

---

## 💻 Tecnologias Utilizadas

- **HTML5** – estrutura e semântica das páginas  
- **CSS3** – estilização e design responsivo  
- **JavaScript** – interatividade e funcionalidades dinâmicas  
- **GitHub Pages** – hospedagem gratuita do site
